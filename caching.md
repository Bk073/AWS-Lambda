# Caching
- Cache is component/mechanism to store frequently accessed data closer to processor, reducing the latency of retrieving the information
Cache is high-speed, small-capacity memory located closer to CPU than main memory
- Cache hit :- data is found in the cache
- Cache miss :- data in not found in cache

## Cache Eviction Policies:

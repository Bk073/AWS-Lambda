# Redshift:
- https://docs.aws.amazon.com/redshift/latest/dg/welcome.html
- Redshift is fully managed warehouse service in the cloud
- Redshift is relational database management system (RDBMS), optimized for high-performance analysis and reporting on very **large datasets.**
- Redshift is based on PostgreSQL
- Redshift is not the same as other SQL database system, its benefits lies in working with large data using parallel processing and columnar data storage and compression
